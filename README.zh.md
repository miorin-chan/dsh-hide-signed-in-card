# 登录后隐藏账号卡片

[English](README.md)

已登录时隐藏左下角的整张账号卡片，未登录时保留原生入口。

在源码目录运行 `pnpm install` 完成构建，再从 **插件** → **添加插件** 选择本目录。
需要 DeepSeek Harness 0.2.2-rc.5 或更新版本及原生账号入口。

设置快捷键仍可使用。已登录时，可在 **插件** 中打开本插件的设置，使用 **意见反馈** 和 **退出登录**。
退出前会确认，并在有运行中的账号任务时提示影响。
停用本插件后，原生账号卡片会恢复。
